---
name: Admin workspace styling
description: Visual-system boundary shared by OFOQ admin and employee portals.
---

Admin and employee surfaces should use the same warm off-white workspace, dark navy navigation, and restrained gold active accents. Keep these overrides scoped to the authenticated workspace shell.

**Why:** The dashboards need one institutional visual language based on the approved reference, while the public site and client portal intentionally retain their separate brand treatment.

**How to apply:** New admin or employee components should reuse the workspace card, table, input, button, and sidebar classes beneath the authenticated shell rather than changing global component styles.
